# Contributing to X Data Scraper

Thanks for your interest in contributing to X Data Scraper.

This project is a local-first Chrome extension for collecting, organizing, and exporting X/Twitter posts for research, AI workflows, and personal knowledge management.

## Before you contribute

Please keep the project direction clear:

- Local-first by default
- Transparent browser extension behavior
- No hosted scraping service
- No credential collection
- No privacy-invasive monitoring
- Responsible use of public or user-accessible content

## Good contribution areas

Useful contributions include:

- Bug fixes for page parsing, storage, export, or sidebar behavior
- Improvements to duplicate detection and incremental capture
- Better export schemas for downstream research and AI workflows
- Clearer documentation for permissions and data handling
- UI improvements that make the extension easier to understand and use
- Tests or validation scripts for packaging and release readiness

## How to contribute

1. Fork the repository.
2. Create a feature branch:

```bash
git checkout -b feature/your-change
```

3. Make a focused change.
4. Test the extension locally in Chrome developer mode.
5. Open a pull request with a clear explanation of:
   - What changed
   - Why it changed
   - How you tested it

## Pull request expectations

A good pull request should be small, specific, and easy to review. Avoid mixing unrelated changes in one PR.

Please include screenshots or short recordings when the change affects the UI.

## Responsible-use boundary

Do not submit changes that enable spam, harassment, credential collection, unauthorized access, or privacy-invasive monitoring.

If a contribution changes permissions, storage behavior, network requests, or data export behavior, explain the privacy and security impact clearly in the pull request.
