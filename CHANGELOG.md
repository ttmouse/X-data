# Changelog

All notable changes to X Data Scraper will be documented in this file.

## [1.2.0] - 2026-06-01

### Changed

- Repositioned the project as a local-first research and AI-workflow Chrome extension.
- Updated extension metadata to describe multi-scenario collection and export workflows.
- Improved README clarity for English-speaking contributors and reviewers.
- Added responsible-use, privacy, contribution, and security documentation.
- Added an explicit MIT license file.

## [1.1.0] - 2025-12-24

### Changed

- Improved project structure for Chrome Web Store packaging.
- Added support for multi-scenario data collection workflows.
- Improved sidebar usage for reviewing, searching, and managing collected posts.
- Updated README to reflect expanded use cases.

## [1.0.0] - 2023-12-01

### Added

- Initial Chrome extension implementation.
- Basic X/Twitter post collection workflow.
- Sidebar interface.
- Auto-scroll support.
